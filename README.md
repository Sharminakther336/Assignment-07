# 🛒 বাজার দর | BazarDor

**Know the Price, Shop Smart! 🇧🇩**

BazarDor is a web-based market price tracking platform that helps users explore essential products and compare market prices over time.

## 🛠️ Technologies Used

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- API Integration
- Better Auth

## ✨ Key Features

1. **Daily Price Tracking** — View available prices of essential products.
2. **Product Categories** — Browse rice, lentils, oil, vegetables, fish, meat, eggs and milk, and spices.
3. **Price Comparison** — Compare today's prices with yesterday's, last week's, and last month's prices.
4. **Dynamic Product Cards** — Display product names, icons, prices, and price changes.
5. **Responsive Design** — Enjoy a user-friendly interface across different screen sizes.
